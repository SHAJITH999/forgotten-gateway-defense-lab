Build a standalone desktop cybersecurity application called:

"Network Exposure Assessment"

IMPORTANT:
This must be a REAL DESKTOP PYTHON GUI application.

DO NOT build:
- A React application
- A web application
- A localhost dashboard
- An Express server
- A browser-based UI
- A fake/mock Nmap dashboard

The application must run directly on the user's desktop as a Python GUI.

==================================================
1. TECHNOLOGY
==================================================

Use:

- Python 3
- Tkinter / ttk for the GUI
- subprocess for executing Nmap
- XML parsing using Python's built-in xml.etree.ElementTree
- threading so the GUI never freezes during a scan

Avoid unnecessary dependencies.

The application should be runnable with:

python3 main.py

==================================================
2. PURPOSE
==================================================

The application is a Level 1 Network Exposure Assessment tool.

Its purpose is:

User enters an authorized target IP
        ↓
Python GUI executes Nmap
        ↓
Nmap performs the real scan
        ↓
Python captures Nmap XML output
        ↓
Python parses the result
        ↓
GUI displays actual discovered services

The application must NEVER fabricate scan results.

==================================================
4. NMAP COMMAND
==================================================

The application should execute this scan:

sudo nmap -sS -sU -sV \
-p T:22,80,443,3000,445,49152,U:53 \
-oX - <TARGET_IP>

Replace:

<TARGET_IP>

with the IP entered by the user.

Use subprocess with an argument list.

DO NOT construct a shell command using string concatenation.

Preferred implementation:

subprocess.Popen(
    [
        "sudo",
        "-n",
        "nmap",
        "-sS",
        "-sU",
        "-sV",
        "-p",
        "T:22,80,443,3000,445,49152,U:53",
        "-oX",
        "-",
        target_ip
    ],
    ...
)

The "-n" option means sudo must not interactively ask for a password.

If sudo permission is unavailable, show a clear GUI error explaining:

"Nmap requires elevated privileges for this scan. Configure appropriate sudo permissions for Nmap or run the application from an authorized privileged environment."

DO NOT store or request the user's sudo password.

==================================================
5. IP VALIDATION
==================================================

Validate the target before executing Nmap.

Use Python's ipaddress module.

Accept:

IPv4
IPv6

Reject:

- Empty input
- Invalid IP addresses
- Shell metacharacters
- Arbitrary commands
- Hostnames unless explicitly supported later

Example:

192.168.1.100

must be accepted.

Something such as:

192.168.1.100; rm -rf /

must NEVER reach subprocess.

==================================================
6. REAL NMAP OUTPUT
==================================================

Use Nmap XML output:

-oX -

This sends XML to stdout.

Do NOT parse the human-readable terminal output.

Parse the XML using:

xml.etree.ElementTree

Extract:

- Port
- Protocol
- State
- Service name
- Product
- Version
- Extra information where available

Only display ports whose Nmap state is:

open

Do not invent results.

443 | TCP | open | https | nginx | ...

IMPORTANT:

These are examples of the UI structure only.

The application must populate the table ONLY from the actual Nmap result.

==================================================
13. ERROR HANDLING
==================================================

Handle:

1. Nmap not installed

Show:

"Nmap was not found on this system."

2. sudo password required

Show:

"Nmap requires elevated privileges. Configure passwordless execution for Nmap or run the scanner with appropriate privileges."

3. Target unreachable

Show:

"Target could not be reached or returned no usable scan results."

4. Nmap timeout

Set a reasonable timeout, such as 180 seconds.

5. Invalid IP

Show:

"Enter a valid IP address."

6. Malformed XML

Show:

"Nmap returned an invalid or incomplete XML result."

7. Permission errors

Show a useful explanation.

Never display a Python traceback directly to the user.

15. OPTIONAL EXPECTED POLICY
==================================================

Do NOT mix expected policy with observed Nmap results.

If a policy comparison section is implemented, clearly separate:

EXPECTED

Configured security policy.

Example:

EXPECTED:

Do not claim that the policy was violated merely because the port is open.

20. SECURITY REQUIREMENTS
==================================================

The target is user-controlled input.

Therefore:

- Validate IP using ipaddress.ip_address()
- Never use shell=True
- Never interpolate the target into a shell command
- Never execute arbitrary user input
- Never accept arbitrary command-line flags from the user
- Use a fixed Nmap argument list
- Set a scan timeout
- Do not collect passwords
- Do not transmit scan results to external services

The application is intended for authorized network/security testing.
